管理后台登录

使用 GitHub 细粒度访问令牌（Fine-grained token）登录。令牌只保存在当前浏览器会话中，不会写入任何代码或服务器，页面只把它发给 api.github.com。请把令牌权限限制为仅 taozi 仓库，退出登录即清除本机令牌。

首次使用：创建仅授权 taozi 仓库的令牌（一次性，约 2 分钟）
  1. 打开 github.com/settings/personal-access-tokens/new（Fine-grained token 创建页）。
  2. Token name 任意（如 themeduo-admin），Expiration 建议 90 天。
  3. Repository access 选 Only select repositories，只勾选 H7ang0/taozi。
  4. Permissions → Repository permissions 中把 Contents 设为 Read and write，其余全部保持 No access。
  5. 点 Generate token，复制 github_pat_… 粘贴到上面的输入框。

为什么不用设备码授权：GitHub 的登录接口不允许浏览器跨域读取（无 CORS 头），纯网页设备码流程不可行。令牌方案不经过任何第三方服务器，权限精确到这一个仓库，随时可在 GitHub 设置里吊销。
